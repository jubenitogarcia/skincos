## Recuperação após a formatação

```powershell
git clone https://github.com/jubenitogarcia/skincos.git
git clone https://github.com/jubenitogarcia/bioevo.git
git clone https://github.com/jubenitogarcia/skincos-local-backup-20260822.git

cd skincos-local-backup-20260822
git fetch --all --tags
git branch -a
```

Para recuperar um snapshot, use o branch correspondente em uma cópia de
trabalho separada, por exemplo:

```powershell
git switch --detach backup/preformat-20260822/130-14c514e1
```

Depois compare ou copie seletivamente para o clone canônico; não faça merge
cego de snapshots históricos. Reautenticação do GitHub, Codex, MCPs, HealthKit
e serviços locais continua sendo necessária porque credenciais e estado de
sessão nunca foram versionados.
