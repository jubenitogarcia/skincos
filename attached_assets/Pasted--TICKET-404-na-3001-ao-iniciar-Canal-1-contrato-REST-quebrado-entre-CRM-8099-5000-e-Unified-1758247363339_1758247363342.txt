## \[TICKET] 404 na 3001 ao iniciar Canal 1 — contrato REST quebrado entre CRM (8099/5000) e Unified (3001)

**Here's what I'm really asking:**
Quero o Canal 1 operando 100% no modelo **porta 3001 + `/whatsapp/1/*`** (start, status, qr, send), sem 404 e sem “Initializing” infinito.

### Sintomas (reprodutíveis)

* CRM (5000) exibe: **“Unified system error: 404 Not Found”** ao **Iniciar Canal**.
* Unified UI em **3001** permanece **Disconnected / Initializing**.
* Orchestrator encaminha → Unified responde **404** para comandos do canal 1.
* Painel detecta canal (ex.: `status=free, ready=false`) mas não ativa.

---

## What am I not seeing here? (pontos cegos prováveis)

1. **Prefixo/basePath divergente**
   Unified montou rotas sob `/api` (ou `/unified`) e o CRM chama `/whatsapp/1/start` direto → 404.

2. **Ordem de middlewares / SPA catch-all**
   `app.get('*', sendIndex)` ou `express.static` antes das rotas `/whatsapp/:account/*` → o SPA consome e devolve 404.

3. **Rewrite/proxy** (8099/5000 → 3001)
   Um rewrite está **removendo `/whatsapp`** ou alterando método (`POST`→`GET`). Clássico: `proxy_pass` com `/` no fim.

4. **Registro tardio de rotas dinâmicas**
   `createDynamicChannelRoutes(id)` só monta rotas **após** ativação/licença; “start” vira 404.
   (O **start** deve existir mesmo sem cliente ativo.)

5. **Auth que responde 404** (em vez de 401/403)
   `requireAuth`/IP allowlist aplicando “security by obscurity” e mascarando erro como 404.

---

**Helper pra listar rotas (debug):**

```js
function listRoutes(app){
  const out=[];
  app._router.stack.forEach(s=>{
    if(s.route){
      const methods = Object.keys(s.route.methods).join(',').toUpperCase();
      out.push({path:s.route.path, methods});
    }else if(s.name==='router' && s.handle.stack){
      s.handle.stack.forEach(r=>{
        const route=r.route;
        if(route) {
          const methods = Object.keys(route.methods).join(',').toUpperCase();
          out.push({path: (s.regexp?.toString()||'') + route.path, methods});
        }
      });
    }
  });
  return out;
}
```

```js
const router = require('express').Router({ mergeParams:true });

  return res.json(qr);
});

router.post('/start', async (req,res)=>{
  const id=req.params.account;
  const ok = await channelManager.start(id); // cria cliente se precisar
  return res.json({ success: ok });
});

router.post('/send-message', async (req,res)=>{
  const id=req.params.account;
  const { to, text } = req.body;
  const r = await channelManager.send(id,{to,text});
  return res.json(r);
});

module.exports = router;
```
