## What am I not seeing here? (pontos cegos típicos)

1. **Header esperado não enviado** (ex.: `X-Internal-API-Key`, `X-API-Key`, `Authorization: Bearer`).
2. **Ambientes desalinhados**: `NO_AUTH=true` no CRM, mas **não** no Unified (ou vice-versa).
3. **Proxy strip de headers**: o proxy remove `Authorization`/custom headers.
4. **Middleware de auth aplicado antes do router** sem exceção para dev.
5. **Cookie/JWT cross-origin** (5000 → 3001) sem `credentials`/`SameSite=None`; se o Orchestrator consome **server-side**, prefira **API key** em header (sem cookies).

## Break this down for me — correção objetiva

### A) Unified (porta 3001): middleware de auth claro e previsível

* Aceite **NO\_AUTH** em dev **ou** **X-Internal-API-Key** (API key compartilhada).
* **Nunca** responda 404 por auth; responda **401/403** com `code`/`hint`.

```js
// unified/auth.js
function requireUnifiedAuth(req, res, next) {
  // 1) Dev bypass
  if (process.env.NO_AUTH === 'true') return next();

  // 2) API Key
  const key = req.get('X-Internal-API-Key') || req.get('X-API-Key') || '';
  const expected = process.env.UNIFIED_API_KEY || '';
  if (expected && key === expected) return next();

  // 3) JWT opcional (se usado)
  const auth = req.get('Authorization') || '';
  if (auth.startsWith('Bearer ')) {
    // validateJWT(...) → se válido: return next();
  }

  console.warn('[AUTH] 401 on %s %s — missing/invalid credentials', req.method, req.originalUrl);
  return res.status(401).json({ code: 'AUTH_REQUIRED', hint: 'Send X-Internal-API-Key or enable NO_AUTH=true' });
}

module.exports = { requireUnifiedAuth };
```

Monte as rotas **com** auth:


### C) Proxy: **não** remova headers

* Se houver http-proxy-middleware/NGINX, **preserve** `Authorization` e custom headers.

**Node (proxy)**

```js
createProxyMiddleware({
  target: process.env.UNIFIED_BASE_URL,
  changeOrigin: true,
  preserveHeaderKeyCase: true,
  onProxyReq: (pReq, req) => {
    // garantir que o header chegue do outro lado
    if (process.env.CRM_UNIFIED_API_KEY) {
      pReq.setHeader('X-Internal-API-Key', process.env.CRM_UNIFIED_API_KEY);
    }
  }
});
```

**NGINX**

```nginx
proxy_set_header Authorization $http_authorization;
proxy_set_header X-Internal-API-Key $http_x_internal_api_key;
```
