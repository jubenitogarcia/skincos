🎯 SERVIÇO AUTOMÁTICO (JÁ INSTALADO E RODANDO!)

   O Actual Budget está configurado para:
   ✅ Rodar automaticamente em segundo plano
   ✅ Iniciar quando você ligar o computador
   ✅ Reiniciar automaticamente se houver problemas

   Para gerenciar o serviço:
   cd backend/apps/actual-server
   ./service-manager.sh

▶ OPÇÃO 1: Menu Interativo
   cd backend/apps/actual-server
   ./manage-actual-budget.sh

   Este script oferece um menu com as seguintes opções:
   • Iniciar/Parar servidor
   • Verificar status
   • Ver logs
   • Fazer backup
   • Restaurar backup
   • Atualizar versão
   • E muito mais!

▶ OPÇÃO 2: Script de Inicialização Rápida
   cd backend/apps/actual-server
   ./start-actual-budget.sh

▶ OPÇÃO 3: Comando Manual
   cd backend/apps/actual-server
   yarn start

                    ⚙️ COMANDOS ÚTEIS
═══════════════════════════════════════════════════════════════

Gerenciar serviço automático:
   cd backend/apps/actual-server
   ./service-manager.sh

Ver status do serviço:
   launchctl list | grep actualbudget

Ver logs em tempo real:
   tail -f backend/apps/actual-server/logs/actual-budget-stdout.log

Parar o serviço:
   launchctl stop com.actualbudget.server

Iniciar o serviço:
   launchctl start com.actualbudget.server

Resetar senha:
   cd backend/apps/actual-server
   yarn reset-password

Fazer backup:
   ./service-manager.sh  (opção 6 do menu manage-actual-budget.sh)

Atualizar para última versão:
   cd backend/apps/actual-server
   git pull origin master
   yarn install
