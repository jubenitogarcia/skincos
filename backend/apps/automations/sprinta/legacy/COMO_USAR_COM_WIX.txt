OPÇÃO 1: Ngrok (Teste Rápido - GRÁTIS) ⭐ RECOMENDADO PARA TESTE
────────────────────────────────────────────────────────────────

1. Instalar ngrok:
   brew install ngrok

2. Criar conta grátis:
   https://ngrok.com/

3. Configurar token (fornecido no dashboard):
   ngrok config add-authtoken SEU_TOKEN_AQUI

4. Expor webhook:
   ngrok http 5001

5. Copiar URL fornecida (ex: https://abc123.ngrok.io)

6. Usar no Wix:
   URL: https://abc123.ngrok.io/webhook/sprinta
   Header: X-Secret-Token: change-this-secret


OPÇÃO 2: Heroku (Produção 24/7 - $5/mês)
────────────────────────────────────────

1. Criar Procfile:
   echo "web: gunicorn webhook_server:app" > Procfile

2. Adicionar gunicorn:
   echo "gunicorn>=21.2.0" >> requirements.txt

3. Deploy:
   heroku create sprinta-webhook
   heroku config:set GITHUB_TOKEN=ghp_seu_token
   heroku config:set WEBHOOK_SECRET=seu-secret
   git add .
   git commit -m "Deploy webhook"
   git push heroku main

4. Usar no Wix:
   URL: https://sprinta-webhook.herokuapp.com/webhook/sprinta

RESUMO:

1. Ativar Dev Mode no Wix

2. Criar arquivo: backend/sendToWebhook.jsw

3. Copiar código do WIX_INTEGRATION.md

4. Atualizar constantes:
   const WEBHOOK_URL = 'https://sua-url-ngrok.com/webhook/sprinta';
   const WEBHOOK_SECRET = 'change-this-secret';

5. No formulário, chamar:
   import { sendToSprintaWebhook } from 'backend/sendToWebhook';

   // Ao submeter:
   const result = await sendToSprintaWebhook([participante]);
