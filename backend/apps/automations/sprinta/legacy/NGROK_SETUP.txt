Erro: "authentication failed"

Erro: "port 5001 is not available"
→ Webhook server não está rodando
→ Execute: python webhook_server.py (terminal 1)

Erro: "connection refused"
→ Verifique se ambos estão rodando
→ Terminal 1: python webhook_server.py
→ Terminal 2: ngrok http 5001

Wix não consegue enviar:
→ Verifique se URL no Wix está atualizada
→ Verifique se tem HTTPS:// (não HTTP://)
→ Verifique WEBHOOK_SECRET idêntico
