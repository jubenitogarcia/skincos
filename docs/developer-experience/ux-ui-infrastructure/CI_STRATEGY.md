# CI strategy

`.github/workflows/ux-ui-infrastructure.yml` is informational (`continue-on-error`) and path-filtered. It installs only local dependencies, runs components, pilot journey, axe, snapshots, Storybook and Lighthouse, then uploads ignored artifacts for seven days. It has read-only repository permissions and no secrets or production target.

After stable baselines, propose category-specific warning gates first, then promote only evidence-backed thresholds to required checks. Do not make SEO a gate for authenticated CRM routes.
