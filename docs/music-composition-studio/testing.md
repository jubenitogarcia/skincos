# Testing

`workflow:music:test` covers schemas, hashes, idempotent jobs/callbacks,
provider gating, cost limits, WAV integrity, FAST/STANDARD/PREMIUM dry-runs,
similarity rejection, voice-consent blocking, selective invalidation, beam DNA,
and additive migration shape.

`workflow:music:build` regenerates schemas, valid/invalid fixture pairs, the
three tier fixtures, and workflows. `workflow:music:validate`
checks graph links, inactive state, forbidden manual/HTTP/command/wait nodes,
secrets, binary audio, and Code-node syntax. The dry-runs prove orchestration
contracts only, not human music quality or a live provider journey.
