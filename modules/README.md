# Modules

`modules/` is the canonical home for active business-facing Skincos domains.

- `site-public/`: public website surface and related operations
- `crm/`: CRM surfaces; `web/` and `api/` are both canonical
- `automations/`: n8n, orb proxy, Evolution API, and workflow assets
- `meta-ads/`: Meta Ads product surface
- `whatsapp/`: WhatsApp-facing products and services

Each module should be navigable on its own, with local docs and ops notes close
to the code they describe.
